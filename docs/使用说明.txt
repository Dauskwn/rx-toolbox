RX 工具箱 V1.8.0
==================

解压后是一个文件夹，双击里面的「Rx工具箱.exe」运行。Windows 10/11（挤服进服识别用系统自带 OCR）。

★ 从 V1.8.0 起主程序固定命名为 Rx工具箱.exe（不带版本号后缀）★
    如果从 V1.7 等旧版升级，旧的桌面“V1.7”快捷方式会失效，请删除旧快捷方式并右键
    「Rx工具箱.exe」重新发送到桌面；此后版本更新都不再改名，快捷方式可持续有效。

★ 请整个文件夹一起用，别只把 exe 拖到桌面 ★
    同目录的 phrases.json 是指令数据，servers.txt 是服务器列表，
    settings.ini 是你的设置，custom.txt 是自定义文本，data-custom.txt 放你改过的指令。
    只拖 exe 出来，程序会找不到数据，表格会是空的。

★ 游戏以管理员运行时，建议本工具也以管理员运行 ★
    右键 exe → 以管理员身份运行。两边权限不同的话，切到游戏里
    热键和自动连点可能被系统拦住。
    窗口左下角显示运行状态，右下角可单击切换主题：护眼浅色（默认）/ 跟随系统 / 夜间深色。

★ 第一次打开如果提示「Windows 已保护你的电脑」★
    这是 Windows 对未签名程序的例行提示，不是报毒。
    点「更多信息」→「仍要运行」即可，之后不会再问。

V1.8.0 版本。

    开源仓库默认随包提供脱敏示例数据表 phrases.json；自用或服主使用可按 JSON 格式
    替换为自己服务器的指令数据，或在界面「编辑条目」中直接增删修改。

本程序不带服务器列表，第一次用要自己加（见「服务器列表」一节）。

----------------------------------------
数据文件 phrases.json
----------------------------------------
指令数据不在 exe 里，而是放在同目录的 phrases.json。
程序启动时读它；读不到的话表格会是空的。

  · 自动更新会自动带上这个文件，正常升级不用管
  · 如果你只手动换了 exe，记得把 phrases.json 也一起放进去
  · 文件是 JSON，格式在第一行就能看懂；想自己加条目，
    建议用界面里的「编辑条目」，改动会写进 data-custom.txt

----------------------------------------
一条指令最多三种写法（右上角切换）
----------------------------------------
有些指令有好几种发送方式，界面右上角会自动出现对应选项，只有该页真的存在才显示：

  ● 主指令            最常见的写法，直接对话框发送
  ○ 原地替换           devforcespawn 变体（只对有 dev 版的行出现）
  ○ 控制台 ulx        必须在游戏控制台里敲的 ulx 写法

切换后，列表右侧显示的就是当前档位下**实际会复制**的文本。
选中的行没有该写法时，自动回落到主指令。

角色表还有「目标 ID」输入框：

  · 留空 → 用 ^（只对自己生效）
  · 填 5 → 命令里的 ^ 换成 “ID 5”，对指定编号的玩家生效

----------------------------------------
分类目录
----------------------------------------
每个数据页右上角有「分类 ▾」，点开是当前页所有分组：

  ■ 枪械            ← 大类（更深更粗）
      冲锋枪  12 条   ← 子类（缩进）
      步枪    48 条
  ■ 投掷与弹药
      投掷物  11 条

单击即跳到该分组（若该分组已折叠会自动展开）；Esc 或点别处关闭。筛选状态下只列当前结果里的分组。
直接点击列表中任意含下属条目的分类标题栏（含 ▓ 大类）即可展开或收起；无下属条目的独立提示条不受影响。

----------------------------------------
标题旁的小字注解
----------------------------------------
很多条目标题右边有一行小一号的斜体灰字，说明适用范围，例如：

  KRISS Vector   短剑
  精巧手法        小偷/扒手
  Class-D Fat · D级人员 胖比   胖宝宝

搜关键词时注解也参与匹配（例如搜 “QRT” 能找到那把枪是给 QRT 用的）。

----------------------------------------
挤服（工具 → 挤服助手）
----------------------------------------
一个开始键 F6，三种模式，用上面的单选切换。
右上角「?」有当前模式的分步操作指南、原理说明，以及带截图的「如何收藏服务器」。

【手动档】—— 不用控制台
① 游戏里 → Play → 服务器列表，选中目标服点「连接」
② 直接在游戏里按 F6（全局热键），开始连发回车
③ 挤进去按 F6 停（勾了 OCR 会自动停）

【单一 IP】—— 需要一个列表里的服
① 先开游戏，停在主菜单
② 在列表里点一下要挤的服务器
③ 切回游戏，按控制台键（默认 ~）打开控制台
④ 控制台开着时按 F6：把 connect 粘进控制台，不停重连
⑤ 挤进去按 F6 停

【收藏轮询】—— 在勾选的服之间轮转
① 先开游戏，停在主菜单
② 列表里勾选要参与的服务器（勾选框在名字左边，「全选 / 全不选」可批量）
③ 打开控制台
④ 按 F6：按顺序把 connect 一条条粘进控制台，一个服一个服试
⑤ 挤进去按 F6 停

★ 两种控制台模式的铁律：先进游戏 → 按 ~ 开控制台 → 再按 F6。
  GMod 会过滤模拟按键，工具打不开控制台，不开就等于空转。

循环间隔：100 / 200 / 300 / 500 / 900 毫秒（默认 200）
运行时顶部常驻「正在挤服 · 按 F6 停止」，键位跟着你改的热键走。
停止后自动清掉剪贴板里残留的 connect 指令（或还原你挤服前复制的内容）。

----------------------------------------
服务器列表
----------------------------------------
  · 底部「IP:端口」框填地址（例如 43.249.193.77:27076），「备注」可留空
  · 点「★ 加入收藏」，或直接回车；「粘贴加服」可从剪贴板一步加入
  · 选中一行点「编辑…」（或双击 / F2）可改备注名和 IP
  · Shift / Ctrl 多选，Delete 批量删除

列表存在程序目录的 servers.txt：
  43.249.193.77:27076|mio1|[CN]Neo RXBreach mio服①服 Q群:491888598
    · 第 1 段 IP:端口（必填）
    · 第 2 段 备注名
    · 第 3 段 真实服务器名（程序探测到会自己写）

四列：备注名 / 真实服务器名 / 人数 / 地址。点表头排序，「人数」能让有空位的排最前。
只有人数列上色：红=满员、绿=有空位、灰=当时没回包。

启动时自动查一次人数和真名（失败的会再串行补查一次）；平时点「↻ 刷新人数」手动刷。
你勾选的服会被记住，下次打开还是那几个。

----------------------------------------
数据表可以自己改
----------------------------------------
每个数据表右上角有「编辑条目」：添加 / 编辑 / 删除 / 上移 / 下移 / 恢复内置。
条目上右键有「修改本条…」，只改这一条。

修改保存在程序目录的 data-custom.txt（仅保存你真正改动过的页签，未改动的页签会继续随官方更新同步）。
在「关于 → 数据更新与本地备份」或「编辑条目 → 备份与更新…」中还可以：
  · 设置程序更新携带新版指令表时的处理策略：「询问我」「自动替换未改页」「仅下载为 phrases.new.json 暂不替换」
  · 在不重装程序的情况下单独拉取最新官方指令表到 phrases.new.json，先对比增删改详情再决定应用哪些页
  · 创建、导出、读取 `.rxbak` 本地完整备份（包含自定义文案、指令表修改、官方底表、软件设置与服务器收藏夹），还原时可只勾选需要的部分，还原前都会自动保护性备份一份到 backups\ 目录。

指令表 / 技能表 / 物品表：单击复制，顶部筛选支持空格分词（例如 `goc 衣服`），Esc 清空。

----------------------------------------
热键（可以在界面里改）
----------------------------------------
F5       准星 换样式
F6       挤服 开始 / 停止（按当前模式）
F7       准星 换颜色
F8       准星 显示 / 隐藏
F9       倒计时 开始 / 重置（按设定时长从头开始）
Ctrl+F9  倒计时 暂停 / 继续
F10      倒计时 显示 / 隐藏悬浮窗
Ctrl+F11 退出工具
Ctrl+F10 关闭 / 开启全部热键（把功能键还给浏览器、录屏软件等）

工具 →「热键设置」：列出当前绑定的 8 个功能键，选中一行点「修改按键…」，
按下想用的键即可（可带 Ctrl / Alt / Shift）；「恢复默认」一键回到出厂。

「关闭热键」：工具页上有按钮，也可以按 Ctrl+F10。关掉后 F5~F10 等就不再被本程序占用，
浏览器刷新、录屏软件都能正常用；再按一次 Ctrl+F10 恢复。
这个开关只对本次运行有效 —— 下次打开工具，热键默认是开启的。

----------------------------------------
倒计时（工具 → 倒计时 · 时间链系统）
----------------------------------------
纯数字透明点击穿透悬浮窗：前台挂起只显示时间与可选标注，不加遮挡背景。
默认内置「标准对局」（18 分钟空方案）与「标准对局(带标注)」（18 分钟对局节点提示）两套方案：
  · 左键点击方案按钮即可切换；右键菜单支持「复制预设」「重命名方案…」「删除此方案」
  · 点击「＋ 新建方案」可直接新建一个干净的 18 分钟空方案并自动切换
  · 时间链支持 3 种触发模式：「持续数秒」「时间区间」「此后一直生效」
  · 每个事件支持组合设置 7 色变色、低频(2s一闪)/中频/高频闪烁 与倒计时下方描边文字标注
  · 支持自定义字号(12~72)、默认色、6 种屏幕锚点与 X/Y 像素微调

----------------------------------------
准星
----------------------------------------
6 种样式、6 色、线宽 / 臂长 / 间隙 / 中心点可调，实时预览。
支持「导入准星图片…」或「粘贴图片」（Ctrl+C 复制任意图片后一点即用）：
PNG / BMP / JPG 都行；粘贴的存成程序目录的 crosshair.png。
大小跟随「臂长 + 间隙」；「清除图片」回到内置矢量样式。
